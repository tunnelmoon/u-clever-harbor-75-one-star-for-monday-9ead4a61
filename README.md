# One Star for Monday

A make.fun bounty entry: a one-line, one-star review of Monday, written as if Monday were a restaurant.

> One star. The waiter served a cold Monday, charged me for the whole week, and kept my weekend as a tip.

`main.ts` (Node 22, stdlib only) writes the line to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`), validating the gate: 1 to 180 characters, a single line, at most 25 words, not only white space, plus a round-trip read-back check.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
